Browser work, part 2 of 2: site notes. Part 1 is `refs/browser.md`, which arrived with the first browser call of this session.

- **Gmail:** `get_page_text` often returns only the "Loading…" shell, so take a screenshot instead. A Gmail web-link token is not the connector's thread id: find the thread by subject/sender with `search_threads`, then `get_thread`. For "Add to Drive", expand the right message first and `find` the button naming the exact file; check the saved name. `find` can name the right file yet return another message's button (2026-10-28, Memory Islands Dev: saved the summary email's `run-log.txt` instead of the receipt), so zoom on the button's attachment row before clicking.
- **Google Cloud console:** opening a service page (e.g. Firestore) can switch that API on. Survey read-only via APIs & Services, IAM, Storage, BigQuery. A menu that silently does nothing usually means a missing project-level role: check IAM.
- **Apps Script:** Extensions → Apps Script on a sheet with no script creates an undeletable bound project. List scripts at script.google.com/home/all instead.
- **Google Admin console:** `get_page_text` is blocked by policy. Use screenshots and coordinate clicks; if a screenshot times out, wait 5 s and retry once.
- **Snowsight:** a look-up (SELECT, WITH, SHOW, DESCRIBE) does not need it: write the query to a `.sql` file in the scratchpad and run `& 'C:\Users\Erez\.claude\scripts\snowflake-read.ps1' -SqlFile '<full path of that file>'` (tool timeout 480000), Claude's own look-only login, no pop-ups. Use Snowsight only for changes, admin look-ups and reads the script refuses. The SQL editor is CodeMirror inside an iframe; the top-page `.cm-content` is the hidden AI chat box. Insert with `document.querySelector('iframe').contentDocument.querySelector('.cm-content').cmView.view.dispatch({changes:{from:0,to:v.state.doc.length,insert:sql}})` (`v` = that view), then click Run. Results: iframe `[role=gridcell]` cells. Use `LISTAGG` for one short cell. For a long cell, select it, press Ctrl+C, then `Get-Clipboard`. `SHOW … ->> SELECT … FROM $1` works. Navigate via the left menu, not typed account paths. For a long script, `Set-Clipboard` from the file, then Ctrl+V into the emptied editor, and compare a SHA-256 of `view.state.doc` with the file before running. If the tab freezes after Run (screenshots and JS time out), `tabs_close_mcp` it and open a fresh tab; the statement already sent still ran, so check its effect by query (AN-1415, 2026-10-25).
- **Tableau Cloud:** the site is `https://us-west-2b.online.tableau.com/#/site/muuula/home` (a guessed `prod-uswest-b` host shows an error page; `sso.online.tableau.com` also works and redirects after sign-in). Read data through the page's session API: `fetch('/vizportal/api/web/v1/<method>')`, POST `{method, params}`, header `X-XSRF-TOKEN` from the `XSRF-TOKEN` cookie. Methods: getExtractTasks, getWorkbooks, getDataConnections, getDataAlerts, getDatasources, getSessionInfo. Map refresh jobs by `targetId`, not by display name. Download workbooks one at a time (`/t/muuula/workbooks/<repositoryUrl>.twbx`).
- **JavaScript results** that look like query strings or encoded data come back as "[BLOCKED: Cookie/query string data]": replace `=` and `@` in returned text, and never return key values.
